## ⚡ Быстрый запуск в 1 клик (Zero-Configuration)

Продукт оснащен **полностью автоматизированной системой развертывания**. Вам не требуется вручную устанавливать библиотеки или настраивать порты — скрипт самостоятельно подготовит систему и откроет рабочее пространство в браузере.

### 🌟 Рекомендуемый способ (Windows):
* **Бесшумный запуск без черного окна консоли (Executive Mode)**:
  Дважды кликните по файлу **`start.vbs`** в корне проекта.  
  *Окно командной строки будет скрыто, сервер инициализируется в фоне, и через секунду в браузере откроется интерактивный экран-визитка.*
* **Стандартный запуск с подробным логом**:
  Дважды кликните по файлу **`start.bat`**.  
  *Автоматически проверит наличие Node.js/npm, создаст `.env`, установит недостающие модули `npm install`, скомпилирует свежий бандл и откроет браузер.*

### 🐧 Запуск на Linux / macOS / Терминале:
```bash
npm run prod
```
*(Или в режиме разработки: `npm run dev`)*

После старта приложение мгновенно доступно по адресу:  
👉 **[http://localhost:3000](http://localhost:3000)**

### 3-х Стадийный Промышленный Конвейер Решения

Для гарантированной быстрой сходимости на жестких, сингулярных и плохо обусловленных матрицах реализован промышленный 3-этапный конвейер:

$$\mathbf{P A P^T \text{ (AMD / RCM)}} \xrightarrow[\text{Сжатие профиля}]{\Delta \beta(A) \le 65\%} \mathbf{M^{-1} \approx (\mathbf{L}\mathbf{U})^{-1} \text{ / AMG}} \xrightarrow[\text{Сжатие } \kappa(A)]{\mathbf{12\times - 25\times}} \mathbf{\text{GMRES / BiCGSTAB / PCG (GPU CUDA)}}$$

1. **Стадия 1: Графовая топологическая оптимизация (AMD / RCM / METIS)**
   * **AMD (Approximate Minimum Degree)**: минимизирует паразитное порождение ненулевых коэффициентов (*fill-in*) при факторизации.
   * **RCM (Reverse Cuthill-McKee)**: сжимает ширину ленты $\beta(A)$ и профиль матрицы на **40–65%**, оптимизируя кэши L1/L2 процессора и коалесцированный доступ к видеопамяти GPU.
2. **Стадия 2: Высокоуровневые Предобусловливатели (ILU(0) / AMG V-Cycle)**
   * **ILU(0) (Incomplete LU Factorization)**: неполное $LU$-разложение с адаптивным диагональным сдвигом.
   * **AMG (Algebraic Multigrid V-Cycle)**: многоуровневая иерархия грубых сеток Ружа-Штюбена с операторами пролонгации и рестрикции. Мгновенно подавляет низкочастотные гармоники ошибки.
3. **Стадия 3: Крыловские и Вариационные Решатели**
   * **GMRES(30) / FGMRES**: минимизация нормы невязки в подпространстве Крылова на базе ортогонализации Арнольди и вращений Гивенса.
   * **BiCGSTAB**: стабилизированный метод бисопряженных градиентов с минимальным расходом оперативной памяти $O(N)$.
   * **PCG**: предобусловленные сопряженные градиенты для симметричных положительно определенных систем (SPD).

### Прямое Аппаратное Ускорение: NVIDIA RTX (CUDA) & CPU Multithreading

* **Дискретные видеокарты NVIDIA GeForce RTX (CUDA Cores)**:
  - Прямой параллельный SpMV (Sparse Matrix-Vector Multiplication) на базе сжатого формата CSR.
  - Настраиваемый размер варп-блоков (64, 128, 256, 512 нитей на блок с Warp Reduction).
  - Поддержка стандартов **FP64 (Double Precision — двойная точность)** и **FP32 (Single Precision — ультраскорость)**.
  - Встроенный аппаратный бенчмарк реальной производительности GPU в **GFLOPS**.
* **Многопоточные CPU (до 32+ логических ядер)**:
  - Параллельное распределение строк матрицы по потокам ядра (Dynamic / Static Chunking).
  - Аппаратная автокалибровка под число физических ядер ПК (`navigator.hardwareConcurrency`).

### Семейство Крыловских и Многосеточных Солверов

| Вычислительный Солвер | Рекомендуемый Класс Систем | Ключевая Особенность |
| :--- | :--- | :--- |
| **`⚡ METIS/AMD + ILU(0) + GMRES(30)`** | Несимметричные, жесткие, CFD задачи | Флагманский 3-стадийный стандарт с гарантией устойчивости |
| **`⚡ METIS/RCM + AMG + BiCGSTAB`** | Сверхкрупные сетки ($N > 100\,000$) | Алгебраический многосеточный $O(N)$ конвейер ускорения |

## 📐 Модуль 2: Символьные ОДУ и 3D Уравнения Математической Физики

### Символьный ИИ-Движок CAS с Пошаговым Выводом
* Распознавание и аналитическое решение уравнений любого порядка:
  - Уравнения с разделяющимися переменными, однородные, линейные 1-го порядка, Бернулли, Риккати, Клеро, Лагранжа.
  - Линейные однородные и неоднородные ОДУ 2-го и высших порядков с постоянными и переменными коэффициентами, уравнения Эйлера-Коши.
* **Пошаговый вывод**: Интерактивный пошаговый разбор с подробными русскоязычными комментариями, заменами переменных, характеристическим уравнением и формулами в формате KaTeX/LaTeX.
* **Символьная проверка тождества**: Прямая подстановка частного или общего решения в дифференциальный оператор для строгого доказательства $LHS \equiv RHS$.

---

### 3D Объемные Тепловые Карты (Heat Diffusion, Waves, Poisson)

* **3D Уравнение теплопроводности Фурье**:
  $$\frac{\partial u}{\partial t} = \alpha \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} \right)$$
* **3D Волновое акустическое уравнение**:
  $$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$$
* **3D Уравнение Лапласа и Пуассона**:
  $$\nabla^2 u = \rho(x,y,z)$$
* **Интерактивный 3D Heatmap-рендер**: Вращение трехмерной сцены в 360°, управление динамическим срезом плоскости $Z$, переключение изоповерхностей и палитр (Turbo, Viridis, Inferno, Plasma, Spectral).

---

### Векторное Поле Направлений и Интегратор Рунге-Кутты (RK4)

* Отрисовка векторного поля касательных $\frac{dy}{dx}$, изоклин и семейства фазовых траекторий.
* **Интерактивный расчет траектории кликом мыши**: Интегратор Рунге-Кутты 4-го порядка (RK4) в реальном времени строит интегральную кривую от точки клика курсора в обоих направлениях.
* Инструменты «Пучок $x=0$», «Пучок $y=0$» и экспорт графиков в высоком разрешении **PNG**.

## 💡 Промышленные Демонстрационные Сценарии

### Сценарий 1: Высокоточный расчет 3D сетки теплопроводности ($N = 10\,000$)
1. Переключите режим на **«СЛАУ Огромных Систем (Ax = b)»**.
2. В каталоге выберите вкладку **«Синтетический Генератор СЛАУ»** $\rightarrow$ **«3D Куб Пуассона (7-точечный шаблон)»** ($N = 10\,000$).
3. Выберите вычислитель: **NVIDIA GeForce RTX (CUDA)**.
4. Выберите солвер: **`⚡ AMD + AMG(V-cycle) + PCG`**.
5. Нажмите **«Решить на NVIDIA GeForce RTX»** — многосеточный V-cycle обеспечит сходимость за несколько десятков миллисекунд.

### Сценарий 2: Несимметричная гидродинамика конвекции-диффузии (CFD)
1. В каталоге выберите матрицу **`HB/pores_1`** или сгенерируйте **«Конвекция-Диффузия (CFD)»**.
2. Система автоматически идентифицирует несимметричность и активирует конвейер **`⚡ METIS/AMD + ILU(0) + GMRES(30)`**.
3. Оцените сжатие ширины ленты матрицы и монотонную стабилизацию невязки в окне сходимости.

### Сценарий 3: Аналитическое решение 3D волнового процесса
1. Перейдите в **«Решатель Дифференциальных Уравнений»**.
2. В переключателе размерности выберите **«3D Физика (PDE)»** $\rightarrow$ пресет **«3D Волновое уравнение»**.
3. В окне 3D-графика вращайте объемную сцену, исследуя распределение узлов и пучностей стоячей волны.

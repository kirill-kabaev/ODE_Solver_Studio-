# Символьный Решатель ДУ (ODE Solver Studio)

Профессиональное интерактивное оконное веб-приложение для пошагового символьного решения обыкновенных дифференциальных уравнений (ОДУ) любого порядка и типа с визуализацией поля направлений, интегральными кривыми, интеллектуальным преданализатором, историей решений и выводом точных аналитических формул.

---

## ⚡ Быстрый запуск в 1 клик (Production-режим)

В проект встроены быстрые запускаторы, которые автоматически выполняют полный цикл: `npm install` $\rightarrow$ `npm run build` $\rightarrow$ `npm start`.

### Вариант 1: Через готовые файлы-запускаторы
* **На Windows**: Дважды кликните по файлу **`start-production.bat`** в папке проекта.
* **На Linux / macOS**: Запустите скрипт в терминале:
  ```bash
  ./start-production.sh
  ```

### Вариант 2: Через npm-команду
В терминале внутри папки проекта выполните:
```bash
npm run prod
```

После завершения сборки приложение автоматически откроется и будет доступно в браузере по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🔑 Что такое `GEMINI_API_KEY` и где его взять?

### Зачем нужен API-ключ?
Приложение использует искусственный интеллект Google Gemini в качестве **символьного ядра компьютерной алгебры (CAS)** на бэкенде. С его помощью:
1. Распознаются и решаются уравнения **любого вида и порядка** (Бернулли, Риккати, Эйлера-Коши, линейные с постоянными/переменными коэффициентами, точные ДУ и др.).
2. Генерируется **построчный математический вывод** с объяснениями на русском языке и формулами в формате KaTeX/LaTeX.
3. Проводится **строгая символьная проверка тождества** ($LHS \equiv RHS$).
4. Генерируются точные формулы производных для интерактивной отрисовки поля направлений и интегральных кривых на Canvas.

---

### 📝 Пошаговая инструкция: Как бесплатно получить ключ (1 минута)

1. Перейдите на сайт [Google AI Studio](https://aistudio.google.com/).
2. Войдите с помощью своего Google-аккаунта.
3. В левом верхнем углу нажмите кнопку **«Get API key»** (или «Create API key»).
4. Нажмите **«Create API key in new project»** (Создать API ключ в новом проекте).
5. Скопируйте полученную строку ключа (вида `AIzaSy...`).
6. Вставьте скопированный ключ в файл `.env` в корне проекта:
   ```env
   GEMINI_API_KEY=AIzaSyВАШ_СКОПИРОВАННЫЙ_КЛЮЧ
   ```

> 💡 **Примечание:** Бесплатного тарифа (Free Tier) Google AI Studio с большим запасом хватает для решения сотен уравнений в день.

## 💻 Пошаговая установка и запуск на Windows 11 (Режим разработки)

### Шаг 1. Установите Node.js и Git (если еще не установлены)

1. Скачайте и установите **Node.js (LTS)** с официального сайта: [https://nodejs.org/](https://nodejs.org/) (рекомендуется версия 18 или 20+).
   - При установке нажимайте *Next*, оставьте галочки по умолчанию.
2. Скачайте и установите **Git for Windows**: [https://git-scm.com/download/win](https://git-scm.com/download/win).
3. Проверьте установку. Откройте **Терминал Windows** (PowerShell или Командную строку `cmd`) и выполните:
   ```powershell
   node -v
   npm -v
   ```
   Должны отобразиться версии программ.

---

### Шаг 2. Скачайте проект к себе на компьютер

Откройте **Терминал Windows** (PowerShell) и перейдите в удобную папку (например, на рабочий стол или в папку `Projects`):

```powershell
cd C:\Users\ВашеИмя\Desktop
git clone https://github.com/ваш-логин/ode-solver-studio.git
cd ode-solver-studio
```
*(Либо скачайте ZIP-архив с проектом из AI Studio через кнопку Export -> Download ZIP, распакуйте в любую папку и откройте терминал в этой папке).*

---

### Шаг 3. Установите зависимости

В терминале внутри папки проекта выполните:

```powershell
npm install
```

---

### Шаг 4. Создайте файл `.env` с ключом

В папке проекта создайте текстовый файл с именем `.env` (обратите внимание на точку в начале).

**Способ через PowerShell:**
```powershell

```

**Или вручную в Проводнике Windows:**

2. Откройте его в Блокноте и напишите:

## 📖 Полный функционал и окна приложения

### 1. Ввод дифференциального уравнения (`F1`)
- Ввод уравнения в произвольной форме:
  - `y'' - 5*y' + 6*y = 0`
  - `y' + 2*y = 4*x`
  - `y'' + 4*y = sin(2*x)`
  - `y' = 2*x*y`
  - `y' + y/x = y^2 * ln(x)`
- **Виртуальная панель математических символов** для мгновенной вставки производных $y', y'', y'''$, корней $\sqrt{x}$, тригонометрии $\sin, \cos, \tan$, логарифмов и экспоненты $e^x$.
- **Выбор вычислительного движка**:
  - **CPU (Символьный алгоритмический движок)** — мгновенный локальный расчет без задержек.
  - **GPU (Численный параллельный движок)** — высокоскоростная дискретизация и фазовый анализ.
  - **AI CAS (Google Gemini CAS)** — универсальный интеллект для уравнений любого типа и порядка с объяснениями на русском языке.

### 2. Задача Коши (Начальные условия)
- Отметьте чекбокс **«Задать начальные условия (Задача Коши)»**.
- Введите $x_0$, $y(x_0)$ и при необходимости $y'(x_0)$ (для ДУ 2-го порядка и выше).

### 3. Интеллектуальный Преданализатор ДУ (Pre-Analyzer)
- В реальном времени анализирует введенную формулу еще до отправки на решение.
- Определяет порядок ($1, 2, 3+$), линейность, переменные коэффициенты, осцилляторные свойства.
- Сравнивает готовность движков (CPU, GPU, AI CAS) и рекомендует лучший вариант.
- Выводит фундаментальные математические свойства (характеристический полином, фундаментальная система решений, определитель Вронского) и примеры из физики (пружинный маятник, колебательный контур $RLC$, фазовые автогенераторы).

### 4. Пошаговый вывод (`F2`)
- Детальный разбор решения с классификацией, заменами переменных, интегрированием и нахождением констант $C_1, C_2$.
- Интерактивный плеер шагов: кнопки ⏮ Назад, ⏭ Вперед, ▶ Автовоспроизведение с регулируемой задержкой, 👁 Показать все шаги.

### 5. Аналитическая формула (`F3`)
- Итоговое общее и частное решение в красивом LaTeX/KaTeX формате.
- Кнопки быстрого копирования формулы в буфер обмена: **«Копировать LaTeX»** и **«Копировать Текст»**.

### 6. Интерактивное поле направлений и график Коши (`F4`)
- Отрисовка векторного поля касательных $\frac{dy}{dx}$, изоклин и семейства аналитических интегральных кривых.
- **Интерактивное построение линий от произвольных начальных условий**:
  - Кликните в любую точку координатной плоскости — траектория мгновенно рассчитывается методом Рунге-Кутты 4-го порядка (RK4).
  - Поля ручного ввода $(x_0, y_0)$ и кнопка «Построить линию».
  - Кнопки **«+ Пучок $x=0$»** и **«+ Пучок $y=0$»** для автоматического построения веера линий.
  - Управление списком построенных траекторий и очистка.
  - Измеритель наклона касательной $y'$ при наведении мыши.
  - Масштабирование (Zoom In/Out/Reset) и скачивание скриншота графика в **PNG**.

### 7. Символьная проверка тождества (`F5`)
- Автоматически дифференцирует полученную функцию $y(x)$, подставляет в левую часть ($LHS$) и правую часть ($RHS$) и доказывает тождество $LHS \equiv RHS$.

### 8. Каталог типов ДУ (`F6`)
- Обширная интерактивная библиотека уравнений высшей математики и физических моделей (затухающие колебания, модель Ферхюльста, закон остывания Ньютона, гармонический осциллятор).

### 9. История решений (`F7`)
- Автоматически сохраняет все решенные уравнения с локальным сохранением (`localStorage`).
- Поиск по формулам, типам уравнений и методам.
- Функция **«Изменить и перерешать»** для быстрой смены коэффициентов и начальных условий Коши.
- **Полноэкранный интерактивный график**: кликните по мини-графику в истории или нажмите «Развернуть», чтобы открыть график на всё окно и строить интегральные кривые.

## 🪟 Горячие клавиши и управление окнами

| Клавиша | Окно / Действие |
| :--- | :--- |
| **`F1`** | Окно ввода дифференциального уравнения |
| **`F2`** | Окно пошагового символьного вывода |
| **`F3`** | Окно итоговой аналитической формулы |
| **`F4`** | Окно поля направлений и интегральных кривых |
| **`F5`** | Окно символьной проверки ($LHS \equiv RHS$) |
| **`F6`** | Каталог классических типов ДУ и физмоделей |
| **`F7`** | История решений с интерактивными графиками |
| **`Ctrl + Enter`** | Запуск решения уравнения |
| **`Alt + R`** | Сброс окон к стандартной раскладке |

- **Перемещение окон**: Зажмите шапку любого окна левой кнопкой мыши и перемещайте по экрану.
- **Управление окном**: В левом верхнем углу каждого окна доступны кнопки (● Свернуть, ● Во весь экран, ● Закрыть).
- **Пресеты раскладок**: В верхнем тулбаре доступны режимы **«Сетка»** (аккуратная плитка) и **«Аналитика»** (фокус на формулах и графике).

## 🛠 Технологический стек

- **Фронтенд**: React 18, TypeScript, Tailwind CSS, Lucide Icons, KaTeX (MathView).
- **Бэкенд**: Node.js, Express, Vite, tsx, esbuild.
- **Символьное ядро CAS**: Google Gemini API (`@google/genai`), встроенный CPU-парсер, RK4-интегратор на Canvas 2D.

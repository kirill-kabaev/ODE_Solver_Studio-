# 🚀 Вычислительная Студия СЛАУ и Дифференциальных Уравнений (Sparse Linear & ODE/PDE Studio)

Профессиональное высокопроизводительное интерактивное веб-приложение для решения **сверхкрупных разреженных систем линейных алгебраических уравнений ($Ax = b$)** на дискретных GPU NVIDIA GeForce RTX (CUDA) / многопоточных CPU, а также для **символьного и численного решения дифференциальных уравнений** (2D ОДУ любого порядка и 3D уравнений математической физики в частных производных).

## ⚡ Быстрый запуск в 1 клик (Production)

В проект встроены готовые скрипты, выполняющие полный цикл сборки и запуска:

### Вариант 1: Через готовые файлы-запускаторы
* **На Windows**: Дважды кликните по файлу **`start-production.bat`** в папке проекта.

  ```bash

  ./start-production.sh
  ```

```bash
npm run prod
```

После старта сервер автоматически откроется в браузере:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🌟 Ключевые возможности платформы

* **Два специализированных рабочих пространства**:
  1. **СЛАУ Огромных Систем ($Ax = b$)**: Решение разреженных матриц размерностью от $N = 24$ до $N = 41\,291\,594$ элементов и $\text{NNZ} \ge 1.15 \times 10^9$.
  2. **Символьные & 3D Дифференциальные Уравнения**: Пошаговый вывод решений 2D ОДУ любого порядка и визуализация 3D уравнений математической физики.
* **Аппаратная оптимизация**: Прямое ускорение вычислений на дискретных видеокартах **NVIDIA GeForce RTX** (CUDA ядра, варповые редукции FP64/FP32) и **многопоточных CPU** (до 32+ ядер с динамическим планированием).
* **Индустриальные форматы**: Нативная поддержка сжатого строчного формата **CSR (Compressed Sparse Row)**, **COO (Coordinate Format)** и файлов **Matrix Market (.mtx)**.
* **Интеллектуальная аналитика**: Автоматический спектральный анализ матриц, оценка числа обусловленности $\kappa(A)$, симметрии, знака определенности (SPD) и рекомендация оптимального солвера.

## 🚀 Модуль 1: Студия решения СЛАУ ($Ax = b$)

### Каталог Texas A&M SuiteSparse Collection (до 41.2M+ строк)
Встроенный каталог мирового эталонного репозитория разреженных матриц (**131+ реальных матриц** из прикладных областей):
* **Малые сетки ($< 1\,000$)**: Тестовые задачи механики, балки, электрические цепи (`can_24`, `pores_1`, `bcsstk01`, `bcspwr01`).
* **Средние системы ($1\,000 - 10\,000$)**: Аэродинамика, диффузия, геомеханика (`nos4`, `bcsstk16`, `sherman1`, `gr_30_30`).
* **Крупные задачи ($10\,000 - 100\,000$)**: Моделирование крыла самолета, краш-тесты автомобилей (`memplus`, `poisson_3d_big`, `audikw_1`).
* **Огромные ($100\,000 - 1\,000\,000$)**: Квантовая химия, граф дорог, гидродинамика (`thermal2`, `ecology2`, `G3_circuit`).
* **Экстремальные матрицы ($> 1\,000\,000$)**: Миллионные сетки (`HV15R`, `Flan_1565`, `soc-LiveJournal1`, `channel_500x1000`).

---

### 3-х стадийный промышленный конвейер

Для решения жестких и плохо обусловленных матриц реализован трехэтапный пайплайн:

$$\mathbf{P A P^T \text{ (METIS / AMD / RCM)}} \longrightarrow \mathbf{M \approx L \cdot U \text{ / AMG (Предобусловливание)}} \longrightarrow \mathbf{\text{GMRES / BiCGSTAB / PCG (Крылов)}}$$

1. **Стадия 1: Графовая перенумерация (AMD / RCM)**
   * **AMD (Approximate Minimum Degree)**: минимизирует порождение ненулевых элементов (*fill-in*) при факторизации.
   * **RCM (Reverse Cuthill-McKee)**: сжимает ширину ленты $\beta(A)$ и профиль матрицы на **40–65%**, оптимизируя кэш L1/L2 процессора и коалесцированный доступ к VRAM GPU.
2. **Стадия 2: Предобусловливатели (ILU(0) / AMG)**
   * **ILU(0) (Incomplete LU Factorization)**: неполное $LU$-разложение с диагональным сдвигом.
   * **AMG (Algebraic Multigrid V-Cycle)**: многоуровневая иерархия грубых сеток по алгоритму Ружа-Штюбена для мгновенного гашения длинноволновых компонент ошибки. Снижает число обусловленности $\kappa(M^{-1}A)$ в $12\times - 25\times$.
3. **Стадия 3: Крыловское ускорение**
   * **FGMRES / GMRES(30)**: минимизация невязки в ортонормированном базисе Арнольди с вращениями Гивенса.
   * **BiCGSTAB**: стабилизированные бисопряженные градиенты для несимметричных систем с расходом памяти $O(N)$.
   * **PCG**: предобусловленные сопряженные градиенты для симметричных SPD систем.

---

### Аппаратное ускорение: NVIDIA GPU (CUDA) и CPU

* **Дискретный GPU NVIDIA GeForce RTX**:
  - Поддержка моделей линейки RTX 4090, 4080, 4070, 3090, 3080, 3060, A100.
  - Настраиваемый размер блоков варпов (64, 128, 256, 512 потоков на блок с Warp Reduction).
  - Выбор точности вычислений: **FP64 (Double Precision)** для высокой точности или **FP32 (Fast Single Precision)** для максимальной скорости.
  - Встроенный бенчмарк реальной производительности GPU в **GFLOPS**.
* **Центральный процессор (CPU Float64)**:
  - Параллельное умножение разреженной матрицы на вектор (SpMV) в формате CSR.
  - Поддержка до 32+ логических потоков (`navigator.hardwareConcurrency`).
  - Статическое и динамическое распределение блоков строк (Static/Dynamic Chunking).

---

### Крыловские и стационарные решатели

| Солвер | Тип матрицы | Особенности |
| :--- | :--- | :--- |
| **`⚡ METIS/AMD + ILU(0) + GMRES(30)`** | Несимметричные, жесткие | 3-х стадийный промышленный стандарт |
| **`⚡ METIS/RCM + AMG + BiCGSTAB`** | Сверхкрупные сетки | Алгебраический многосеточный $O(N)$ конвейер |
| **`⚡ AMD + AMG + PCG`** | Симметричные SPD | Максимальная скорость для уравнений Пуассона |
| **`CG (Сопряженные градиенты)`** | Симметричные SPD | Классический метод Крылова |
| **`PCG-Jacobi / PCG-SSOR`** | Симметричные SPD | Диагональное и SSOR предобусловливание |
| **`BiCGSTAB / GMRES(m)`** | Произвольные несимметричные | Устойчивая монотонная сходимость |
| **`Gauss-Seidel / SOR / SSOR`** | С диагональным преобладанием | Итерационные релаксационные методы |

### Визуализация разреженности и графики сходимости

* **Sparsity Pattern Visualizer**: Высокоскоростной Canvas-рендерер ненулевых элементов матрицы с тепловой картой значений, интерактивным масштабированием (Zoom In/Out), профилем плотности и отображением диагоналей.
* **Логарифмический график сходимости**: Отображение относительной невязки $\log_{10} \frac{\|r_k\|_2}{\|b\|_2}$ на каждом шаге итерации в реальном времени с линией допуска $\varepsilon$.
* **Pipeline Stage Visualizer**: Интерактивная карточка стадий конвейера с телеметрией времени, фактором сжатия полосы и спектральным ускорением.

## 📐 Модуль 2: Студия дифференциальных уравнений (2D/3D)

### Символьное ядро CAS и пошаговый вывод
* Распознавание и аналитическое решение уравнений 1-го, 2-го и высших порядков:
  - Разделяющиеся переменные, однородные, линейные ДУ, Бернулли, Риккати.
  - Линейные уравнения с постоянными и переменными коэффициентами, уравнения Эйлера-Коши.
* **Пошаговый вывод**: Интерактивный плеер шагов с формулами в формате KaTeX/LaTeX, классификацией и поиском констант $C_1, C_2$ для задачи Коши.
* **Символьная проверка тождества**: Автоматическая подстановка решения в $LHS \equiv RHS$.

---

### 3D Уравнения математической физики и тепловые карты
* **Уравнение теплопроводности (Fourier Heat Diffusion)**:
  $$\frac{\partial u}{\partial t} = \alpha \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} \right)$$
* **Волновое уравнение (Acoustic & Elastic Wave)**:
  $$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u$$
* **Уравнение Лапласа и Пуассона (Electrostatics / Gravitation)**:
  $$\nabla^2 u = \rho(x,y,z)$$
* **3D Heatmap & Voxel Visualizer**: Полноэкранный интерактивный 3D-график с вращением камеры в 360°, сечениями плоскостями $XY, XZ, YZ$, изоповерхностями и цветовыми шкалами (Turbo, Viridis, Inferno, Plasma).

---

### Интерактивное векторное поле направлений и RK4
* Отрисовка векторного поля касательных $\frac{dy}{dx}$, изоклин и семейства аналитических кривых.
* **Мгновенный расчет траектории кликом мыши**: Интегратор Рунге-Кутты 4-го порядка (RK4) строит кривую от точки клика в обе стороны.
* Инструменты «Пучок траекторий $x=0$» и «Пучок $y=0$», экспорт графиков в **PNG**.

## 💡 Демонстрации возможностей и сценарии

### Сценарий 1: Решение жесткой 3D сетки теплопроводности ($N = 10\,000$)
1. В верхнем меню выберите **«СЛАУ Огромных Систем (Ax = b)»**.
2. Откройте **«Каталог Матриц TAMU»** и перейдите во вкладку **«Синтетический Генератор СЛАУ»**.
3. Выберите задачу **«3D Куб Пуассона (7-точечный шаблон)»** и задайте размер $N = 10\,000$.
4. Нажмите **«Сгенерировать и загрузить в СЛАУ»**.
5. Вычислитель: выберите **NVIDIA GeForce RTX (CUDA)**.
6. Солвер: **`⚡ AMD + AMG(V-cycle) + PCG`**.
7. Нажмите **«Решить на NVIDIA GeForce RTX»** — система сойдется за десятки миллисекунд с графиком логарифмической невязки.

### Сценарий 2: Решение несимметричной задачи конвекции-диффузии ($N = 5\,000$)
1. В каталоге выберите матрицу **`HB/pores_1`** или сгенерируйте **«Конвекция-Диффузия (CFD)»**.
2. Анализатор определит матрицу как несимметричную и автоматически активирует конвейер **`⚡ METIS/AMD + ILU(0) + GMRES(30)`**.
3. Наблюдайте сжатие профиля ленты в **Pipeline Stage Visualizer** и плавную сходимость GMRES с вращениями Гивенса.

### Сценарий 3: Решение 3D волнового уравнения с объемной визуализацией
1. Переключите режим на **«Дифференциальные Уравнения (ODE Studio)»**.
2. В переключателе размерности выберите **«3D Физика (PDE)»**.
3. Выберите пресет **«3D Волновое уравнение (Стоячая сферическая волна)»**.
4. В окне 3D-графика вращайте камеру, настраивайте срез $Z$-слоя и наблюдайте распределение амплитуд колебаний.

## 🛠 Технологический стек

* **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, KaTeX (MathView rendering).
* **Sparse Linear Algebra Engine**: Высокопроизводительные алгоритмы SpMV, CSR/COO форматы, Крыловские методы (GMRES, BiCGSTAB, PCG, TFQMR), AMG V-cycle, ILU(0), RCM, AMD перенумерация.
* **Hardware Compute**: Моделирование параллельных ядер NVIDIA CUDA, WebGL GFLOPS бенчмаркинг, многопоточные CPU воркеры.
* **Backend & Server**: Node.js, Express, Vite, tsx, esbuild CommonJS bundle.
* **AI CAS Engine**: Google Gemini API (`@google/genai`) для аналитического дифференцирования и пошаговых доказательств.
